# Pieces & Play
Pieces & Play is a Godot Engine project bringing classic board games together in one place. Play familiar favorites like chess and checkers, with more games planned.

## Features
- A growing collection of classic board games
- Built with the Godot Engine
- Designed for an easy-to-use, welcoming play experience

## Project Status
Pieces & Play is a work in progress. Features and available games may change as development continues.
